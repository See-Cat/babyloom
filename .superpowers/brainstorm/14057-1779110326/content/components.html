N. Modal / BottomSheet / ActionSheet §4.7 / §4.12 / §4.13

三种弹窗已经有专门的交互预览,见 popups.html。本节只列出关键视觉数值快查。

Modal:surface-2 底 / radius-lg 24 / shadow-soft-lg / 内边距 22/24 / 进场 scale .96→1 + translateY(-50% +8 → -50%) 250ms。
BottomSheet:surface-2 / 顶圆角 24 / 向上阴影 0 -8px 24px rgba(61,52,40,.14) / handle 36×4 / 内边距 18/20/28 / 进场 translateY 100%→0 300ms。
ActionSheet:surface-2 / radius-base 18(不用 24)/ 项 padding 16/18 / 居中对齐 / 取消块隔 8px 独立 / 进场 translateY 120%→0 300ms。

📌 使用方式

  • Codex / Claude 实施时:打开本页对照每个组件的视觉与状态;实现完成后截图对照
  • 设计语言变更:先改 规范文档,再同步本页;两处保持一致
  • 新增组件:先加在规范 §4,然后在本页加对应 section,确保 toc 链接更新
  • 视觉回归基线:Playwright 截本页,所有组件状态进截图库
