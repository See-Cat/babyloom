# BabyLoom 产品功能文档

## 产品概述

**产品名称**：小日子 (BabyLoom)  
**产品定位**：宝宝生活记录应用  
**目标用户**：有宝宝的家庭成员  
**部署方式**：Docker + QNAP NAS

## 系统架构

### 三端架构

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  客户端APP   │     │  管理后台PC  │     │  后端服务API │
│   (PWA)     │◄────►│   (Web)     │◄────►│  (NestJS)   │
│  React+Vite │     │ React+AntD  │     │  PostgreSQL │
└─────────────┘     └─────────────┘     └─────────────┘
       │                    │                    │
       └────────────────────┴────────────────────┘
                          │
                    ┌─────────┐
                    │  Nginx  │
                    │ 反向代理 │
                    └─────────┘
```

### 技术栈

- **客户端APP**：React 18 + TypeScript + Vite + PWA + Framer Motion
- **管理后台**：React 18 + TypeScript + Vite + Ant Design 5
- **后端服务**：NestJS + TypeScript + TypeORM + PostgreSQL
- **部署**：Docker + Docker Compose + Nginx

## 一、客户端APP功能

### 1.1 登录模块

**功能描述**：
- 用户通过账号密码登录
- 无注册功能，所有账号由管理后台创建
- JWT Token 认证，7天有效期
- 登录状态持久化（localStorage）

**页面元素**：
- 应用名称和标语展示
- 账号输入框
- 密码输入框
- 登录按钮
- 错误提示

### 1.2 时光（Timeline）

**功能描述**：
- 按时间倒序展示宝宝成长记录
- 支持分页加载（每次20条）
- 日期分组显示（今天、昨天、更早）
- 点击记录进入详情页

**记录卡片包含**：
- 发布者头像和昵称
- 发布时间
- 文字内容
- 图片/视频（支持轮播）
- 里程碑标签

**交互效果**：
- 卡片入场动画（staggered fade + translateY）
- 图片轮播（手势滑动）
- 点击卡片缩放反馈

### 1.3 画廊（Gallery）

**功能描述**：
- 以网格形式展示所有照片和视频
- 按月份分组
- 支持筛选：全部/照片/视频
- 瀑布流布局（支持不同尺寸）

**图片展示**：
- 正方形、竖向、横向多种比例
- 视频带播放图标和时长
- 点击可查看详情

### 1.4 日历（Calendar）

**功能描述**：
- 月历视图
- 标记有记录的日期（小圆点）
- 今天高亮显示
- 月份切换

**视觉设计**：
- 7列网格布局
- 星期标题行
- 日期格子
- 事件标记点

### 1.5 添加记录（Add Entry）

**功能描述**：
- 文字输入（多行文本框）
- 添加里程碑标签（多选）
- 添加照片/视频（拍照或从相册选择）
- 保存记录

**交互流程**：
1. 点击底部"+"按钮
2. 弹出底部操作菜单（拍照/相册）
3. 文字输入
4. 选择里程碑标签（底部弹出选择器）
5. 点击保存

**底部弹出菜单**：
- 毛玻璃背景遮罩
- 从底部滑入动画
- 操作选项列表
- 取消按钮

### 1.6 里程碑（Milestones）

**功能描述**：
- 展示所有里程碑标签
- 搜索功能
- 按使用频率排序
- 点击可筛选相关记录

**里程碑卡片**：
- 图标
- 名称
- 描述
- 关联记录数量

### 1.7 我的（Profile）

**功能描述**：
- 宝宝信息展示
  - 头像（首字母）
  - 姓名
  - 年龄
- 统计数据
  - 记录总数
  - 照片数量
  - 视频数量
  - 里程碑数量
- 宝宝切换（多宝宝支持）
- 菜单列表
  - 里程碑
  - 家庭成员
  - 设置

### 1.8 记录详情（Detail）

**功能描述**：
- 全屏查看图片/视频
- 文字内容展示
- 发布者信息
- 发布时间
- 里程碑标签

**图片查看**：
- 全屏黑色背景
- 图片轮播
- 关闭按钮（右上角）
- 指示器

## 二、管理后台功能

### 2.1 登录模块

**功能描述**：
- 管理员账号登录
- 账号从配置文件初始化
- JWT Token 认证

### 2.2 数据看板（Dashboard）

**功能描述**：
- 统计卡片
  - 总记录数
  - 总用户数
  - 总照片数
  - 总视频数
- 最近记录列表
- 用户增长趋势

### 2.3 记录管理（Entries）

**功能描述**：
- 记录列表（表格形式）
- 搜索功能
- 筛选功能（按宝宝、按类型、按日期）
- 查看详情
- 编辑记录
- 软删除/恢复
- 永久删除（垃圾桶）

### 2.4 媒体管理（Media）

**功能描述**：
- 媒体列表（网格/列表视图）
- 预览功能
- 筛选（照片/视频）
- 软删除/恢复
- 永久删除

### 2.5 用户管理（Users）

**功能描述**：
- 用户列表
- 创建用户（账号/密码/昵称）
- 编辑用户信息
- 设置用户角色（admin/member）
- 软删除/恢复用户
- 查看用户关联的宝宝

### 2.6 宝宝管理（Babies）

**功能描述**：
- 宝宝列表
- 创建宝宝（姓名/出生日期/性别）
- 编辑宝宝信息
- 管理关联用户
- 设置用户权限（canCreate/canDelete/canEdit）

### 2.7 里程碑管理（Milestones）

**功能描述**：
- 里程碑列表
- 创建里程碑（名称/图标/颜色/描述）
- 编辑里程碑
- 启用/禁用里程碑
- 排序功能

### 2.8 垃圾桶（Trash）

**功能描述**：
- 展示已删除的记录/媒体/用户
- 恢复功能
- 永久删除
- 自动清理（30天后永久删除）

### 2.9 系统设置（Settings）

**功能描述**：
- 系统信息展示
- 配置管理
- 备份设置
- 存储管理

## 三、后端服务功能

### 3.1 认证模块（Auth）

**功能**：
- 用户登录（JWT Token）
- Token 刷新
- 管理员初始化（从配置文件读取）
- 配置同步（重启时同步管理员信息）

**配置文件** (`config/app.json`)：
```json
{
  "admin": {
    "username": "admin",
    "password": "admin123",
    "nickname": "管理员"
  },
  "app": {
    "name": "小日子",
    "maxUploadSize": 52428800,
    "allowRegistration": false
  },
  "storage": {
    "uploadPath": "/app/uploads",
    "backupEnabled": true
  },
  "features": {
    "enableTrash": true,
    "trashRetentionDays": 30
  }
}
```

### 3.2 用户模块（User）

**功能**：
- CRUD 操作
- 软删除/恢复
- 密码加密（bcrypt）
- 角色管理（admin/member）
- 字段过滤（不返回密码）

### 3.3 宝宝模块（Baby）

**功能**：
- CRUD 操作
- 多宝宝支持
- 宝宝-用户关联管理
- 权限控制

### 3.4 记录模块（Entry）

**功能**：
- CRUD 操作
- 软删除/恢复
- 里程碑关联（多对多）
- 媒体关联
- 分页查询
- 日历数据查询

### 3.5 媒体模块（Media）

**功能**：
- 文件上传（支持照片/视频）
- 宝宝维度存储（`uploads/{babyId}/{year}/{month}/`）
- 软删除/恢复
- 文件服务（静态资源）

### 3.6 里程碑模块（Milestone）

**功能**：
- CRUD 操作
- 可用里程碑查询（排除已选）
- 与记录的多对多关联

### 3.7 数据库设计

**核心表**：
- users（用户表）
- babies（宝宝表）
- baby_users（宝宝-用户关联表，含权限字段）
- entries（记录表）
- media（媒体表）
- milestones（里程碑表）
- entry_milestones（记录-里程碑关联表）

**特性**：
- UUID 主键
- 软删除（deletedAt）
- 时间戳（createdAt/updatedAt）
- 外键关联
- 索引优化

## 四、部署功能

### 4.1 Docker 部署

**服务组成**：
- api（NestJS 后端）
- db（PostgreSQL 数据库）
- client（PWA 客户端）
- admin（管理后台）
- nginx（反向代理）

### 4.2 NAS 挂载

**挂载点**：
- `/share/Container/babyloom/config` - 配置文件
- `/share/Container/babyloom/uploads` - 上传文件
- `/share/Container/babyloom/data` - 数据库数据

### 4.3 配置热更新

**特性**：
- 修改 `config/app.json` 后重启 API 容器即可生效
- 无需重建镜像

## 五、安全功能

### 5.1 认证安全
- JWT Token 认证
- Token 7天过期
- 密码 bcrypt 加密
- 登录失败处理

### 5.2 数据安全
- 软删除机制
- 字段过滤（不返回敏感信息）
- SQL 注入防护（TypeORM）
- XSS 防护

### 5.3 访问控制
- 角色权限（admin/member）
- 宝宝-用户权限（canCreate/canDelete/canEdit）
- API 鉴权

### 6.1 离线支持
- Service Worker 缓存
- 图片缓存（CacheFirst）
- API 缓存（NetworkFirst）

### 6.2 安装支持
- Web App Manifest
- 添加到主屏幕
- 独立运行模式

### 6.3 推送通知
- 预留接口（暂未实现）

## 七、多宝宝支持

### 7.1 宝宝维度
- 所有记录按宝宝隔离
- 媒体文件按宝宝存储
- 切换宝宝时数据自动切换

### 7.2 权限控制
- 妈妈/爸爸：完整权限
- 爷爷/奶奶：查看权限
- 自定义权限（canCreate/canDelete/canEdit）

---

## 八、数据管理

### 8.1 软删除
- 客户端删除 = 软删除（不可见）
- 管理后台可查看已删除数据
- 垃圾桶模块可恢复或永久删除

### 8.2 数据备份
- 数据库备份（pg_dump）
- 文件备份（rsync）
- 自动备份（预留接口）

### 8.3 数据清理
- 自动清理30天前的软删除数据
- 手动清理垃圾桶
