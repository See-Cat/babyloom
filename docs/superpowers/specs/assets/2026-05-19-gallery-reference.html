③ 全屏 viewer(Gallery + Entry 详情共用)
设计要点
  • 顶栏简化 — 与 Timeline 一致:标题(画廊)+ 副标({宝宝名} · 共 N 张),右侧不放任何按钮。切换宝宝功能从所有页面 header 移除,统一收到 Profile/Me 子页(P5 已实现的 BabyTabs 横向 chip 列表与 baby-pill 都删掉)
  • 月分组标题 sticky — position: sticky; top: 0; background: var(--bg)。"2025 年 5 月 · 23 张"。滚动时本月标题贴顶,下个月标题来时顶替。提供时间感的同时不占恒定空间
  • 3 列正方 — 间距 4px(比 EntryComposer 的 6px 略紧,因为整页都是图);圆角 16px(--radius-sm)。不用阴影、不加 hover lift,平面铺陈
  • 视频角标 — 右下 ▶ 0:18(分:秒),半透明黑底 + blur,与媒体内容色无关都清晰
  • 点击行为 — 缩略图点击:有 entryId 关联 → 直接进 /entry/[id](详情页内部用 viewer 浏览);无 entryId(独立媒体) → 当场打开全屏 viewer
  • 空态(②) — emoji 📸 + 标题 + 引导文案 + 主 CTA 跳 /entry/new。不显示空的 Tabbar 标题("画廊")副标改为"还没有照片"提示
  • 全屏 viewer(③) — 黑底全屏;顶部毛玻璃头(关闭 ✕ / 媒体所属 entry 摘要 / ⋯ 更多)+ 居中媒体(自适应宽高比)+ 底部缩略图条(选中加白边)。Gallery 直接点开独立媒体 / Entry 详情点 carousel 都用这个组件
  • viewer ⋯ 菜单 — ActionSheet:"下载到本地 / 设为里程碑封面(若进入的是里程碑相册) / 移到回收站"。具体项目按权限和上下文显示
  • 无限滚动 — 月分组按 24 张/页分批加载;到底显示"已经到底啦 🌱"小字脚标
