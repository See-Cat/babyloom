③ 点 ⋯ · ActionSheet
设计要点
  • 无标题栏 — 详情页是"阅读"场景,删掉"记录"标题文字,让媒体或内容占据顶部注意力。只留两个浮起按钮(返回 / ⋯ 更多)
  • 带媒体时:顶部按钮浮在媒体上,背景 rgba(255,255,255,.85) + blur(8px) 半透明胶囊。这样按钮无论叠在什么颜色上都清晰
  • 无媒体时:顶部按钮变 solid 透明,直接落在页面背景上,无毛玻璃
  • 媒体区:1:1 方形(微博/小红书规格),底部 dots 指示器(选中胶囊化),顶部居中 1 / 3 当前/总数胶囊。可左右滑动切换
  • 时间行:完整日期 + 时刻 + 月龄胶囊。月龄是只读信息,样式比时间淡(--surface 底奶油色)
  • 内容段落:最大 --text-base * 1.15 ≈ 15.5px,行高 1.75,white-space: pre-wrap 保留换行。让回忆"舒展"
  • 里程碑 tag:小号 accent tag(mint 底浅 + mint 文字),只读,不能直接在详情页修改(编辑时回到 EntryComposer)
  • 作者 meta:与上方内容用 1px border-light 极淡分隔。展示作者头像 + 姓名 + 完整记录时间(可与 occurredAt 不同,这里展示 createdAt)
  • ⋯ ActionSheet:权限决定项目可见性 — owner / editor + 自创 → 显示「编辑 / 移到回收站」;viewer / non-owner → 不显示 ⋯ 按钮(无可执行操作)
  • 编辑(emphasized mint)= 跳 /entry/[id]/edit;移到回收站(destructive)= 弹二级确认 Modal,确认后 POST /api/entries/[id]/trash → Toast "已移到回收站 [撤销]"
  • 媒体放大:点 carousel 任一张图打开全屏 viewer(position: fixed;黑底;轮播 + 双指缩放 + 退出 ✕)。这是独立组件,需另写
