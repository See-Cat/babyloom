③ 点月份标题 · 年月 picker
设计要点
  • 顶栏简化 — "日历" + 副标 "{宝宝} · {月龄}",右侧无按钮(切换宝宝走 Profile)
  • 月份切换 — 三段式 ‹ | 5 月按钮(浮起胶囊) | ›。中间按钮可点开 BottomSheet 年月 picker(2 列年/月滚轮 + "回到本月/出生月"快捷 chip)。比"上一月/下一月"文字按钮更紧凑
  • 日历 cell:
    • 普通日:数字居中 + 无修饰
    • 有记录:数字下方 5px mint 圆点(底部 6px)。不区分内容类型(简化;详情在下方预览)
    • 今天:数字 mint 加粗 + 1.5px mint 圆环包围
    • 选中日(任意点):mint 实底 + 白字 + 加粗;若同时是今天,圆环被实底覆盖,但仍显示白底 dot
    • 非本月:opacity 0.4,不可点
  • 周末标记 — 表头"日 / 六"色淡(--fg-disabled),提供视觉锚点
  • 无连续 ring/hover/transform — 日期格只用背景色区分状态,无 hover lift(mobile-first)
  • 下方"当日预览" — 比直接跳 /timeline?date= 更顺手。选了哪天就在下方展示那天的 mini-card(头像 + 作者 + 时间 + 内容 + 缩略图)。预览区可滚动,容纳多条
  • 当日年龄块 — 预览头部第二行,显示选中日的月龄(例 1岁3月 · 第 457 天),mint-bg pill。不重复宝宝名字(顶部副标已有)。回看过去某天时能直观看到"那时候宝宝多大",承接 babyloom 的成长记录定位;空白日也显示,提示"那天宝宝多大,要不要补记一条"
  • 无记录日:预览区显示 🌱 + 文案 + "给这一天写一条"主 CTA → 跳 /entry/new?babyId=&occurredAt=2025-05-20T...(传日期作 occurredAt 默认)
  • 滑动手势(可选,P6+):左右滑日历区切换月份;触摸优先,桌面靠 ‹ / › 按钮
  • 性能 — 月数据(daySet:有记录的日期 ISO 集合)按月预取;切月触发新一次 server fetch(SWR)
