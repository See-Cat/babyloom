# P4 Trash Bin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an owner/editor-visible trash bin with list, restore, purge, and empty-tab flows, backed by parent-chain visibility checks.

**Architecture:** Keep the implementation surgical against the current P0-P3 code. Add small trash query/purge helpers, extend the existing API authorization wrapper for non-id global routes, then build `/profile/trash` with plain local UI patterns already used in profile pages. Add an ESLint rule that blocks new `entries`/`media` queries without a `babies` join in app/lib code.

**Tech Stack:** Next.js App Router, React client components, Drizzle ORM, SQLite, Vitest, ESLint 9 flat config, Playwright.

Create `eslint-rules/parent-chain-join.js`, export it from `eslint-rules/index.js`, and add `'babyloom/parent-chain-join': 'error'` to `eslint.config.mjs`.
