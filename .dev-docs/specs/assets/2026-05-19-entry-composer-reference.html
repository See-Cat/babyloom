设计要点
  • 顶栏 save 而非底部 save — 移动端键盘弹起时底部被遮挡,save 放顶部右侧最稳。返回(‹)+ 标题 + 保存,三段式
  • 保存按钮 disabled 态 — 空内容时 disabled(灰 + 不能点),输入任意字符后自动激活
  • Context row — 头像 + "记录给 [小乐]" + 时间胶囊,告知用户"我在给谁记录、什么时间发生"。时间默认"今天 + 当前时刻",点胶囊拉起 DatePicker(年/月/日)+ TimePicker(时/分)
  • Textarea — 最低 160px 高,auto-grow 最多 6 行;字符计数当前/2000 仅当 ≥50% 时显示(否则隐藏不打扰)
  • 里程碑 chip 行 — 横向 wrap 排列(不滚动);最多内联 6 个,超过则"+ 更多"打开 BottomSheet 多选。chip 选中态 = mint 实底 + 白字;未选中 = surface 奶油底 + 暖棕字。UI 上无图标:用户自定义里程碑时不需要再选 icon,减负。
    实施备注:DB schema 中 milestones.icon 字段保留(扩展用,如未来定制视觉/导出报表/AI 自动选图);UI 渲染层不读取 / 不展示
  • 媒体 grid — 3 列,每个 cell 1:1。已上传 = 缩略图 + 右上 ×。上传中 = surface 底 + 居中 spinner + 底部进度条。最后一格永远是 dashed 的"+ 添加"
  • 无底部按钮区 — 顶部已有"保存",删除原来底部的"取消 / 保存"两按钮,信息密度更高。"取消" = 顶部 ‹ 返回(若有未保存内容应弹 ActionSheet 确认)
  • 键盘弹起处理 — body 设 overflow-y: auto + iOS interactive-keyboard-dismiss,焦点在 textarea 时自动滚动让焦点可见
  • 未保存离开 — 点 ‹ 返回时,若 textarea 非空 / 有媒体 / 有里程碑选中,弹 ActionSheet:"放弃当前记录"(destructive) / "继续编辑"(取消)
  • 时间胶囊点开(③) — BottomSheet 顶部 segmented tab 切换"日期 / 时间";内容区是滚轮(日期 3 列年月日 / 时间 2 列时分);下方 3 个快捷 chip "今天/昨天/前天"。年份范围 = 宝宝出生日 ~ 今天(不能选未来,避免无效数据)。点"今天"chip 会把日期+时间同时设为当前
  • "+ 更多" 里程碑(④) — BottomSheet 列出全部里程碑,扁平 chips wrap(无分类、无 schema 变更)。已选项实底 mint,可在 sheet 内勾选/取消。顶部右侧 "完成 (N)" 显示当前已选数。自定义里程碑入口不在此处,放到 Profile/里程碑管理子页(独立页面,与本 sheet 解耦)
