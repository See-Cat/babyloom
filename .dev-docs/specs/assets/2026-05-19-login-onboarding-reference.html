设计要点
  • 无 AppShell / Tabbar — pre-auth 流程是全屏沉浸,顶部仅留 6px 极淡彩条做装饰,提示品牌色
  • 居中对齐 — 表单竖向居中,左右 24px padding;Onboarding 由于内容多,改为 justify-content: flex-start; padding-top: 48px
  • Brand mascot — Login 用 🌱(成长的种子),Onboarding 用 👶(直接呼应主题)。emoji 替代矢量 logo,零成本零依赖
  • 错误展示 — 不用红字一行,改为 error-bg 红底圆角块 + ! 圆点 icon,信息密度高且可被聋哑用户/读屏察觉;同时把出错字段 border 染红
  • 性别用 segmented control — 替代丑陋的 native <select>,3 个选项 × Tag-pill 风格,选中态用 surface-2 浮起 + soft 阴影。a11y 上 role="radiogroup" + aria-checked
  • Onboarding 头像 — 大圆 avatar picker(88px)居中,右下叠相机角标(28px mint 圆 + 3px 页面色描边)。未上传时显示名字首字作为 fallback,跟随名字输入实时变化。fallback 头像底色按 hash(babyId) % 8 分配,一旦分配跟随终生。头像可选(下方一行小字说明,无需独立 dashed Card)
  • 步骤指示 — Onboarding 顶部 step dot:当前步骤为胶囊形 mint,后续为小灰圆。本期只有 1 步,但保留结构以便后续多步扩展
  • Footer link — Login 底部一行"家里还没有账号? README →",承接 babyloom 自托管定位
  • 生日选择器 — 不用原生 <input type="date">(桌面端浏览器外观各异、Animal Crossing 风不搭)。改成可点击的 date-row 触发 BottomSheet 滚轮选择器:三列 (年/月/日),中间高亮带,选中项加大加粗,上下渐隐 mask。年份范围 = 今年 - 10 ~ 今年(宝宝最大 10 岁,后续可配置)。a11y 上保留 aria-label="选择生日",确认后回填到 date-row 文字
