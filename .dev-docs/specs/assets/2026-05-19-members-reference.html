③ 点成员卡片 · 管理 ActionSheet
设计要点
  • 整页 owner-only — 路由层做权限判断,editor / viewer 完全访问不到这个页面
  • 成员列表(①):
    • "你自己"用 primary-bg 浅薄荷底 + mint 半透明边突出(类比 Profile 的"正在记录"卡)。自己卡片不带 chevron(无可执行管理操作 — 改自己信息走 /profile/me)
    • 每张卡:头像 + 昵称 + role badge + meta(@用户名 · 加入年月)+ chevron
    • 三种 role badge:owner = "主理人"(mint-bg)/ editor = "编辑成员"(surface-2 灰)/ viewer = "仅查看"(灰)。同 Me hub 的 role 表现一致
    • 底部 dashed "+ 添加成员"卡跳 /profile/members/new
    • 底部 hint 文案说明"点击卡片管理",承接上面的 chevron 提示
  • 添加成员表单(②):
    • 顶部 avatar picker:88px 大圆,点击打开 ActionSheet "拍照 / 从相册选择 / 移除头像"。右下叠相机 SVG 角标(28px mint 圆 + 3px 页面色描边,营造"按钮叠在头像上"的浮起感)
    • 头像非必填,未上传时显示昵称首字作为 fallback。字符随昵称输入实时变化(打字时直接预览效果)。昵称为空时显示占位 ?
    • fallback 头像底色:首次保存成员时按 hash(userId) % 8 分配,落到 8 色头像板某一色;一旦分配后跟随该用户终生不变
    • 顶部不再放装饰 emoji,因为 avatar 本身已经承担了"视觉锚点"角色
    • 有顶栏(因为是 owner 在已登录状态里走的子页,与 Login / Onboarding 的沉浸态不同)
    • 顶栏右上"保存"(空字段时 disabled),沿用 EntryComposer 模式 — 避开键盘遮挡。返回(‹)= 取消,未保存时弹 ActionSheet 二次确认
    • 4 个字段 + hint:每个 label 下有一行 hint(--text-xs --fg-soft)解释填什么/为什么,降低首次使用心理门槛
    • 角色 segmented control(两选项):编辑成员 / 仅查看。"主理人"不在可选范围(owner 唯一,迁移所有权另走流程)。下方 seg-detail 区域随选择变化,解释当前角色权限
    • 用户名校验:实时校验长度 / 字符集 / 不重复;失败时 input 染红 + 下方 err-msg 块
    • 密码字段默认为 focus 状态(说明"键盘焦点),hint 提示"告诉家人后他们登录后可自己改"
  • 成员管理 ActionSheet(③):
    • 点非自己的成员卡 → ActionSheet 弹起。顶部 sheet-title 小灰文字显示成员标识(奶奶 · @nainai),提供操作目标的强反馈
    • 4 项操作:改名/改头像 · 重置密码 · 切换角色 · 移除成员(destructive)
    • "切换角色"文案动态:editor 显示"切换为「仅查看」",viewer 显示"切换为「编辑成员」"。无需多级菜单
    • 重置密码 / 改名 → 跳出独立的小 Modal 表单(各 1 个输入框)。不在 ActionSheet 内放表单(违反 ActionSheet 的"快速选择"语义)
    • 移除成员二次确认 Modal(沿用 §4.7):"确认移除 N 名成员? 该成员将无法登录,但他们已记录的内容会保留。",destructive 按钮在右
  • "主理人"特例:
    • 主理人(owner)自己的卡片不显示 chevron,无 ActionSheet
    • 本期不支持迁移主理人角色(留 P6+,涉及到所有权迁移的复杂度)
    • 主理人想改自己的名字 / 密码 / 头像 → 走 /profile/me
